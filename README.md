# 📅 Habit Tracker

Mi primer proyecto completo desarrollado con **Python** y **Tkinter**.

Es una aplicación de escritorio que permite registrar hábitos diarios, marcar su cumplimiento y visualizar estadísticas de progreso.

---

## 🚀 Características

- ✅ Registrar nuevos hábitos.
- ✅ Agregar hábitos en cualquier momento.
- ✅ Marcar hábitos cumplidos por día.
- ✅ Guardar automáticamente los datos en formato JSON.
- ✅ Cargar la información al iniciar la aplicación.
- ✅ Consultar los hábitos cumplidos de un día específico.
- ✅ Visualizar estadísticas individuales de cada hábito.

---

## 🛠️ Tecnologías utilizadas

- Python 3
- Tkinter
- JSON
